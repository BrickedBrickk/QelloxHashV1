## Frozen Manifest

The manifest at [docs/qualification/CANDIDATE_A.json](qualification/CANDIDATE_A.json) is the authoritative algorithm specification. Any implementation must produce outputs identical to the reference implementation for all canonical test vectors.

### Finalization Notes

Phase 5 deconstruction identified three items that are intentional design choices, not unresolved issues:

- **`flags` field** (instruction bits [31:28]): Computed during instruction encoding but intentionally unused by the execution engine. Exists in the encoding for format completeness and potential future use. Does not affect current algorithm outputs.
- **`DATASET_LOAD` naming**: Opcode 0x12 performs `dst = src_a + src_b + imm5` (address computation only). Actual dataset/scratchpad fetches with dependency chains occur in the separate `dataset_reads()` phase. This is by design.
- **`CROSS_LANE_ROUNDS` constant**: Defined as 2 but not used as a loop bound in the code. The cross-lane mixing function `cross_lane_mix()` is called once per execution pass. The constant is informational.

None of these items affect the algorithm's deterministic outputs. The manifest SHA and all canonical vectors remain valid and unchanged.

## 1. Scope

## 2. Terminology and Glossary

| Term | Definition | Also Called |
|------|-----------|-------------|
| **Lane** | One of 32 parallel execution threads processing the same instruction simultaneously. Each lane has its own set of 32 registers but shares the scratchpad with all other lanes. Maps to a GPU thread within a warp/wavefront. | thread, SIMD lane |
| **Register** | A u32 storage location within a lane. 32 registers per lane, 1024 total. | — |
| **Scratchpad** | A shared u32 array of 12,288 words (48 KiB). All lanes can read and write. Used for intermediate storage and as proxy for dataset reads. | shared memory, LDS |
| **Instruction** | A 32-bit encoded VM operation. Contains opcode, destination, two source registers, a 5-bit immediate, and flags. | — |
| **Program** | 112 instructions plus a 32-byte cross-lane shuffle map. Generated deterministically from the mining seed. | microprogram |
| **Pass** | One complete execution cycle: (1) execute all 112 instructions, (2) cross-lane mixing, (3) dataset reads. Four passes per hash. | — |
| **Subgroup** | A group of 8 consecutive lanes that perform butterfly mixing together. 4 subgroups per candidate. | — |
| **Mining Seed** | 32 bytes derived from SHA-256("QelloxHashV1/seed/v1" \|\| header \|\| nonce). Drives program generation and state initialization. | seed |
| **Epoch Seed** | 32 bytes derived from SHA-256("QelloxHashV1/epoch-seed/v1" \|\| epoch). Drives dataset/cache generation. | — |
| **Light Cache** | ~16 MiB array of 64-byte items. Used to derive dataset items on demand. Nodes use this instead of the full dataset. | cache |
| **Dataset** | ~2 GiB array of 128-byte items. Derived from light cache. Miners hold this in VRAM. | DAG |
| **Work Digest** | 32-byte SHA-256 hash of the final VM state (registers + scratchpad). Intermediate value before finalization. | — |
| **PoW Digest** | 32-byte SHA-256("Qellox/QelloxHashV1" \|\| work_digest). The final value compared against the target. | final hash, pow hash |
| **Target** | A 256-bit value. The PoW digest must be ≤ target for a valid solution. | difficulty target |
| **Epoch** | A range of 75,000 blocks. Dataset and cache are regenerated each epoch. | — |
| **Cross-Lane Map** | A 32-byte array where map[i] ≠ i. Defines which lane each lane exchanges registers with during mixing. | shuffle map |
| **FNV Hash** | A simple hash: `x.wrapping_mul(0x01000193).wrapping_add(0x811C9DC5)`. Used for dataset read indexing. | — |
| **Domain Separator** | An ASCII string included in SHA-256 inputs to ensure different uses of SHA-256 produce different outputs. | tag, domain |
| **Keystream** | Pseudo-random bytes generated by repeated SHA-256 of the seed. Used to derive program instructions. | — |

```
Offset  Size  Field

```

### 8.2 Epoch Seed

epoch_seed = SHA-256("QelloxHashV1/epoch-seed/v1" || epoch_le[4])

## 9. Program Generation

### 9.1 Keystream Expansion

The seed is expanded into a keystream of `ceil((112*4 + 32) / 32) * 32 = 480` bytes:

```
for i in 0..15:
    keystream[i*32..(i+1)*32] = SHA-256("QelloxHashV1/program-expand/v1" || seed || le32(i))
```

### 9.2 Instruction Generation

For each position `i` in 0..112:

1. Read 4 bytes from keystream at offset `i*4` as little-endian u32 = `raw`
2. Select opcode using weighted group selection (see §9.3)
3. Extract operand fields from `raw`:
   - `dst   = (raw >> 8) & 0x1F`
   - `src_a = (raw >> 13) & 0x1F`
   - `src_b = (raw >> 18) & 0x1F`
   - `imm5  = (raw >> 23) & 0x1F`
4. Compute flags based on opcode
5. Encode instruction as 32-bit word

### 9.3 Opcode Selection

Seven groups with weights summing to 100:

| Group | Opcodes | Weight |
|-------|---------|--------|
| 0: Arithmetic | ADD32, SUB32, ADD_IMM32, MADD32 | 25 |
| 1: Bitwise | XOR32, AND32, OR32, NOT32, XOR_IMM32 | 20 |
| 2: Rotation | ROTL32, ROTR32, ROTL_IMM32 | 15 |
| 3: Multiplication | MUL_LO32, MUL_HI32, MUL_ROT32 | 15 |
| 4: Bit manipulation | POPCNT32, CLZ32, BITSELECT, BYTE_PERMUTE | 10 |
| 5: Memory | SCRATCH_LOAD, SCRATCH_STORE, DATASET_LOAD | 12 |
| 6: Cross-lane | LANE_SHUFFLE | 3 |

Group selection:
```
group_selector = raw.wrapping_add(position.wrapping_mul(0x9E3779B9))
selection = group_selector % 100
walk groups subtracting weight until selection < weight
```

Opcode within group:
```
secondary = (raw >> 16).wrapping_add(position.wrapping_mul(0x85EBCA6B))
opcode = group[secondary % group.len()]
```

### 9.4 Flags

- Memory opcodes (0x10–0x12): `flags = ((raw >> 24) & 0x0F) | 0x01`
- Cross-lane (0x13): `flags = (raw >> 24) & 0x03`
- Others: `flags = (raw >> 28) & 0x0F`

**Note:** Flags are computed but never read by the execution engine. They exist in the encoding but have no semantic effect.

### 9.5 Guaranteed Operations Injection

After generating all 112 instructions, specific positions are overwritten:

For each pass p in 0..3:
- Position `p * 28`: DATASET_LOAD with `dst = seed[p] & 0x1F`, `src_a = seed[p+4] & 0x1F`
- Position `p * 28 + 2`: LANE_SHUFFLE with same operands

Additionally:
- Position 1: SCRATCH_LOAD with `dst = seed[8] & 0x1F`, `src_a = seed[9] & 0x1F`
- Position 3: SCRATCH_STORE with `dst = seed[9] & 0x1F`, `src_a = seed[8] & 0x1F`, `imm5 = 4`

### 9.6 Cross-Lane Map Generation

From keystream bytes at offset `112*4 = 448`:
```
for i in 0..32:
    map[i] = keystream[448 + i] % 32
    if map[i] == i:
        map[i] = (map[i] + 1) % 32
```

## 10. Opcode Definitions

### 10.1 Instruction Encoding

```
Bits [7:0]    opcode
Bits [12:8]   dst (register index 0–31)
Bits [17:13]  src_a (register index 0–31)
Bits [22:18]  src_b (register index 0–31)
Bits [27:23]  imm5 (5-bit immediate)
Bits [31:28]  flags (unused in execution)
```

### 10.2 Opcode Table

| ID | Mnemonic | Semantics | Notes |
|----|----------|-----------|-------|
| 0x01 | ADD32 | `R[dst] = R[src_a].wrapping_add(R[src_b])` | Wrapping u32 |
| 0x02 | SUB32 | `R[dst] = R[src_a].wrapping_sub(R[src_b])` | Wrapping u32 |
| 0x03 | XOR32 | `R[dst] = R[src_a] ^ R[src_b]` | Bitwise |
| 0x04 | AND32 | `R[dst] = R[src_a] & R[src_b]` | Bitwise |
| 0x05 | OR32 | `R[dst] = R[src_a] \| R[src_b]` | Bitwise |
| 0x06 | NOT32 | `R[dst] = !R[src_a]` | Bitwise; src_b ignored |
| 0x07 | ROTL32 | `R[dst] = R[src_a].rotate_left(R[src_b] & 31)` | Shift masked to 0–31 |
| 0x08 | ROTR32 | `R[dst] = R[src_a].rotate_right(R[src_b] & 31)` | Shift masked to 0–31 |
| 0x09 | MUL_LO32 | `R[dst] = (R[src_a] * R[src_b]) as u32` | Low 32 bits of 64-bit product |
| 0x0A | MUL_HI32 | `R[dst] = ((R[src_a] as u64 * R[src_b] as u64) >> 32) as u32` | High 32 bits |
| 0x0B | MADD32 | `R[dst] = R[src_a].wrapping_add(R[src_b].wrapping_mul(imm5))` | Multiply-add |
| 0x0C | POPCNT32 | `R[dst] = R[src_a].count_ones()` | Population count; output 0–32 |
| 0x0D | CLZ32 | `R[dst] = R[src_a].leading_zeros()` | Count leading zeros; output 0–32 |
| 0x0E | BITSELECT | `R[dst] = (R[src_a] & R[imm5]) \| (R[src_b] & !R[imm5])` | Conditional select |
| 0x0F | BYTE_PERMUTE | `R[dst] = byte_permute(R[src_a], R[src_b])` | See §10.3 |
| 0x10 | SCRATCH_LOAD | `R[dst] = S[(R[src_a] + imm5) % 12288]` | Read from scratchpad |
| 0x11 | SCRATCH_STORE | `S[(R[src_b] + imm5) % 12288] ^= R[src_a]` | XOR into scratchpad |
| 0x12 | DATASET_LOAD | `R[dst] = R[src_a].wrapping_add(R[src_b]).wrapping_add(imm5)` | Compute address only |
| 0x13 | LANE_SHUFFLE | `R[dst] = L[(lane+1+imm5)%32].R[src_a]` | Cross-lane read |
| 0x14 | ADD_IMM32 | `R[dst] = R[src_a].wrapping_add(imm5)` | Immediate add |
| 0x15 | XOR_IMM32 | `R[dst] = R[src_a] ^ imm5` | Immediate XOR |
| 0x16 | ROTL_IMM32 | `R[dst] = R[src_a].rotate_left(imm5 & 31)` | Immediate rotate |
| 0x17 | MUL_ROT32 | `R[dst] = (R[src_a] * R[src_b] as u32).rotate_left(imm5 & 31)` | Multiply then rotate |

### 10.3 BYTE_PERMUTE Detail

```
a_bytes = R[src_a].to_le_bytes()  // [a0, a1, a2, a3]
b_bytes = R[src_b].to_le_bytes()  // [b0, b1, b2, b3]
result[i] = a_bytes[b_bytes[i] & 0x03]  for i in 0..4
R[dst] = u32::from_le_bytes(result)
```

Each byte of src_b selects which byte of src_a goes to that position (masked to 0–3).

## 11. VM Execution Model

### 11.1 State

```
registers: [[u32; 32]; 32]   // registers[lane][reg]
scratchpad: [u32; 12288]      // shared across all lanes
```

### 11.2 Execution Model

The VM is **SIMT-like**: all 32 lanes execute the same instruction simultaneously. The reference implementation uses a sequential loop over lanes, but the semantics are as if all lanes execute in parallel.

**No barriers or synchronization** exist within instruction execution. Lanes interact only through:
1. The shared scratchpad (via SCRATCH_LOAD/SCRATCH_STORE)
2. Cross-lane register reads (via LANE_SHUFFLE)
3. The cross-lane mixing phase

### 11.3 Per-Pass Structure

Each of the 4 passes consists of:
1. Execute all 112 instructions (lane-parallel)
2. Cross-lane mixing
3. Dataset reads with dependency chains

Registers and scratchpad persist across passes. Pass index affects dataset read behavior.

## 12. State Initialization

### 12.1 Register Initialization

For each lane l in 0..31, for each register r in 0..31:
```
hash = SHA-256("QelloxHashV1/reg-init/v1" || seed || le32(l) || le32(r))
registers[l][r] = u32::from_le_bytes(hash[0..4])
```

Total: 1024 SHA-256 invocations.

### 12.2 Scratchpad Initialization

```
blocks = ceil(12288 / 8) = 1536
for i in 0..1536:
    hash = SHA-256("QelloxHashV1/scratch-init/v1" || seed || le32(i))
    for j in 0..8:
        idx = i * 8 + j
        if idx < 12288:
            scratchpad[idx] = u32::from_le_bytes(hash[j*4..(j+1)*4])
```

Total: 1536 SHA-256 invocations.

## 13. Cross-Lane Mixing

### 13.1 Shuffle Map Exchange

```
for lane in 0..32:
    peer = cross_lane_map[lane]
    peer_values[lane] = registers[peer].copy()

for lane in 0..32:
    for reg in 0..32:
        registers[lane][reg] ^= peer_values[lane][reg].rotate_left(reg & 31)
```

### 13.2 Subgroup Butterfly

Subgroups of 8 lanes: {0–7}, {8–15}, {16–23}, {24–31}.

Within each subgroup, 3 stages of butterfly operations:

**Stage 1 (stride=1):**
```
Pair (0,1), (2,3), (4,5), (6,7) within each subgroup
For each pair (i, j) and each register r:
    a = registers[i][r]
    b = registers[j][r]
    registers[i][r] = (a + b).rotate_left(7)
    registers[j][r] = (b - a).rotate_left(13)
```

**Stage 2 (stride=2):**
```
Pair (0,2), (1,3), (4,6), (5,7) within each subgroup
Same operations
```

**Stage 3 (stride=4):**
```
Pair (0,4), (1,5), (2,6), (3,7) within each subgroup
Same operations
```

All addition/subtraction wrapping u32.

## 14. Dataset Reads

### 14.1 Per-Pass Dataset Reads

For each pass p, for each lane l:
```
chain = registers[l][0].wrapping_add(registers[l][4]).wrapping_add(p * 0x01000193)

for r in 0..7:
    index = chain.wrapping_mul(0x01000193).wrapping_add(0x811C9DC5)
    scratchpad_index = index % 12288
    value = scratchpad[scratchpad_index]

    dst_reg = (r * 4 + l + p) % 32
    registers[l][dst_reg] = registers[l][dst_reg]
        .wrapping_add(value)
        .rotate_left((r + 3) & 31)

    chain = value
        .wrapping_add(registers[l][(r + 1) % 32])
        .wrapping_mul(0x01000193)

    scratchpad[scratchpad_index] ^= registers[l][(r + 2) % 32]
```

### 14.2 Dependency Chain Analysis

The chain variable is updated using the value just read:
```
chain[n+1] = (value[n] + registers[l][(n+1)%32]) * 0x01000193
```

This creates a true serial dependency: `chain[n+1]` depends on `value[n]`, which depends on `chain[n]`. Therefore:

**Actual dependency depth per pass: 8 serial reads**
**Total across 4 passes: 32 serial reads**

The claim "8 serial reads × 4 passes = 32 dependent accesses" is **literally true**.

However, lanes are independent during dataset reads — lane l's reads do not depend on lane l' reads. So within a workgroup, 32 lanes can execute their dependency chains in parallel.

## 15. State Reduction

### 15.1 Work Digest Computation

```
hasher = SHA-256()
hasher.update("QelloxHashV1/reduce/v1")

for lane in 0..32:
    for reg in 0..32:
        hasher.update(registers[lane][reg].to_le_bytes())  // 4 bytes each

// Scratchpad hash (only first 256 words = 1024 bytes)
sp_hasher = SHA-256()
sp_hasher.update("QelloxHashV1/scratchpad/v1")
for i in 0..256:
    sp_hasher.update(scratchpad[i].to_le_bytes())
sp_digest = sp_hasher.finalize()

hasher.update(sp_digest)  // 32 bytes
work_digest = hasher.finalize()  // 32 bytes
```

### 15.2 Important Detail

Only the first 256 of 12,288 scratchpad words are included in the reduction. This means 97.9% of scratchpad state is discarded during reduction. The scratchpad's influence on the final hash is mediated entirely through its effect on register state (via SCRATCH_LOAD during program execution and dataset reads).

## 16. Final Digest

```
pow_digest = SHA-256("Qellox/QelloxHashV1" || work_digest)
```

Where `"Qellox/QelloxHashV1"` is 19 ASCII bytes, and `work_digest` is 32 bytes. Total input: 51 bytes.

## 17. Target Comparison

```
meets_target(pow_digest, target) = true iff pow_digest ≤ target
```

Comparison is byte-by-byte big-endian (index 0 is most significant). This is equivalent to comparing the 256-bit integers they represent.

## 18. Dataset Generation

### 18.1 Light Cache

Item count: `floor((16777216 + 131072 * epoch) / 64)`

**Item 0:**
```
cache[0] = SHA-256("QelloxHashV1/cache-item/v1" || epoch_seed || le32(0))
```
Expanded to 16 u32 words: pairs of (hash_word, rotate_left(hash_word, 11)).

**Item i (i > 0):**
```
seed_item = seed_to_cache_item(epoch_seed)
cache[i] = mix_cache_items(cache[i-1], seed_item, i)
```

**Mixing rounds (3 rounds):**
```
for round in 0..3:
    for i in 0..item_count:
        parent = cache[cache[i][0] % item_count]
        cache[i] = mix_cache_items(cache[i], parent, i)
```

### 18.2 Dataset Item Generation

For item at index `idx`:
```
item[0..16] = cache[idx % cache_count]

for p in 0..512:
    mix_val = item[p % 32].wrapping_add(p).wrapping_mul(0x01000193).wrapping_add(0x811C9DC5)
    parent = cache[mix_val % cache_count]
    for w in 0..32:
        item[w] = item[w].wrapping_add(parent[w % 16]).rotate_left(7) ^ (p.wrapping_mul(0x9E3779B9))

for w in 0..32:
    item[w] = item[w].wrapping_mul(0x01000193).wrapping_add(idx as u32).rotate_left(w & 31)
```

## 19. Complete Pipeline

```
QelloxHashV1(header[80], nonce u64, epoch u32) -> [u8; 32]:

    // 1. Mining seed
    seed = SHA-256("QelloxHashV1/seed/v1" || header || le64(nonce))

    // 2. Generate program
    program = GenerateProgram(seed)  // 112 instructions + 32-byte map

    // 3. Initialize state
    registers = InitializeRegisters(seed)  // 1024 SHA-256
    scratchpad = InitializeScratchpad(seed)  // 1536 SHA-256

    // 4. Execute 4 passes
    for pass in 0..4:
        // 4a. Execute 112 instructions across all 32 lanes
        for inst in program.instructions:
            ExecuteInstruction(state, inst)

        // 4b. Cross-lane mixing
        CrossLaneMix(state, program.cross_lane_map)

        // 4c. Dataset reads with dependency chains
        DatasetReads(state, pass)

    // 5. Reduce state
    work_digest = ReduceState(state)

    // 6. Finalize
    pow_digest = SHA-256("Qellox/QelloxHashV1" || work_digest)

    return pow_digest
```

| Verification | Once per winning nonce | Same as mining |

## 21. Error Conditions

- Invalid opcodes (not 0x01–0x17): treated as NOP
- Register indices always valid (5-bit field, 0–31)
- Scratchpad indices always valid (modulo 12288)
- No integer overflow/underflow undefined behavior (wrapping)
- No out-of-bounds memory access possible

## 23. Pseudocode

Implementation-independent pseudocode sufficient for independent reimplementation.

### Notation

- `||` = byte concatenation
- `le32(x)` = x as little-endian 4-byte array
- `le64(x)` = x as little-endian 8-byte array
- `SHA-256(x)` = standard SHA-256 hash of byte string x
- `R[l][r]` = register r of lane l (u32)
- `S[i]` = scratchpad word at index i (u32)
- `a.wrapping_add(b)` = (a + b) mod 2³²
- `a.wrapping_sub(b)` = (a - b) mod 2³²
- `a.wrapping_mul(b)` = (a × b) mod 2³²
- `a.rotate_left(n)` = circular left shift of a by n bits
- `a ^ b` = bitwise XOR
- `a & b` = bitwise AND
- `a | b` = bitwise OR
- `!a` = bitwise NOT
- `a.count_ones()` = population count
- `a.leading_zeros()` = count of leading zero bits

### GenerateProgram(seed: [u8; 32]) -> (instructions: [u32; 112], cross_lane_map: [u8; 32])

```
// Keystream expansion
keystream = empty byte array of length 480
for i in 0..15:
    keystream[i*32 .. (i+1)*32] = SHA-256("QelloxHashV1/program-expand/v1" || seed || le32(i))

// Instruction generation
instructions = new array of 112 u32 values
for i in 0..112:
    raw = le32_to_u32(keystream[i*4 .. i*4+4])  // little-endian u32
    opcode = SelectOpcode(raw, i)
    dst   = (raw >> 8) & 0x1F
    src_a = (raw >> 13) & 0x1F
    src_b = (raw >> 18) & 0x1F
    imm5  = (raw >> 23) & 0x1F
    flags = ComputeFlags(opcode, raw)
    instructions[i] = EncodeInstruction(opcode, dst, src_a, src_b, imm5, flags)

// Guaranteed ops injection
positions_per_pass = 28
for pass in 0..4:
    base = pass * positions_per_pass
    instructions[base]   = EncodeInstruction(0x12, seed[pass]&0x1F, seed[pass+4]&0x1F, 0, pass&0x1F, 0x01)
    instructions[base+2] = EncodeInstruction(0x13, seed[pass]&0x1F, seed[pass+4]&0x1F, 0, pass&0x1F, 0x00)

instructions[1] = EncodeInstruction(0x10, seed[8]&0x1F, seed[9]&0x1F, 0, 0, 0x01)
instructions[3] = EncodeInstruction(0x11, seed[9]&0x1F, seed[8]&0x1F, 0, 4, 0x01)

// Cross-lane map
cross_lane_map = new array of 32 u8 values
for i in 0..32:
    cross_lane_map[i] = keystream[448 + i] % 32
    if cross_lane_map[i] == i:
        cross_lane_map[i] = (cross_lane_map[i] + 1) % 32

return (instructions, cross_lane_map)
```

### SelectOpcode(raw: u32, position: u32) -> u8

```
GROUP_OPCODES = [
    [0x01, 0x02, 0x14, 0x0B],      // Arithmetic: weight 25
    [0x03, 0x04, 0x05, 0x06, 0x15], // Bitwise: weight 20
    [0x07, 0x08, 0x16],             // Rotation: weight 15
    [0x09, 0x0A, 0x17],             // Multiplication: weight 15
    [0x0C, 0x0D, 0x0E, 0x0F],       // Bit manipulation: weight 10
    [0x10, 0x11, 0x12],             // Memory: weight 12
    [0x13]                           // Cross-lane: weight 3
]
GROUP_WEIGHTS = [25, 20, 15, 15, 10, 12, 3]  // sum = 100

group_selector = raw.wrapping_add(position.wrapping_mul(0x9E3779B9))
selection = group_selector % 100

group_index = 0
for i in 0..7:
    if selection < GROUP_WEIGHTS[i]:
        group_index = i
        break
    selection -= GROUP_WEIGHTS[i]

secondary = (raw >> 16).wrapping_add(position.wrapping_mul(0x85EBCA6B))
opcode_index = secondary % len(GROUP_OPCODES[group_index])
return GROUP_OPCODES[group_index][opcode_index]
```

### ComputeFlags(opcode: u8, raw: u32) -> u8

```
if opcode >= 0x10 and opcode <= 0x12:
    return ((raw >> 24) & 0x0F) | 0x01
else if opcode == 0x13:
    return (raw >> 24) & 0x03
else:
    return (raw >> 28) & 0x0F
```

### EncodeInstruction(opcode, dst, src_a, src_b, imm5, flags) -> u32

```
return opcode | (dst << 8) | (src_a << 13) | (src_b << 18) | (imm5 << 23) | (flags << 28)
```

### InitializeState(seed: [u8; 32]) -> (registers: [[u32; 32]; 32], scratchpad: [u32; 12288])

```
// Register initialization
for l in 0..32:
    for r in 0..32:
        hash = SHA-256("QelloxHashV1/reg-init/v1" || seed || le32(l) || le32(r))
        R[l][r] = le32_to_u32(hash[0..4])

// Scratchpad initialization
for i in 0..1536:
    hash = SHA-256("QelloxHashV1/scratch-init/v1" || seed || le32(i))
    for j in 0..8:
        idx = i * 8 + j
        if idx < 12288:
            S[idx] = le32_to_u32(hash[j*4 .. (j+1)*4])
```

### ExecuteInstruction(state, instruction: u32)

```
opcode = instruction & 0xFF
dst   = (instruction >> 8) & 0x1F
src_a = (instruction >> 13) & 0x1F
src_b = (instruction >> 18) & 0x1F
imm5  = (instruction >> 23) & 0x1F

for l in 0..32:
    match opcode:
        0x01: R[l][dst] = R[l][src_a].wrapping_add(R[l][src_b])
        0x02: R[l][dst] = R[l][src_a].wrapping_sub(R[l][src_b])
        0x03: R[l][dst] = R[l][src_a] ^ R[l][src_b]
        0x04: R[l][dst] = R[l][src_a] & R[l][src_b]
        0x05: R[l][dst] = R[l][src_a] | R[l][src_b]
        0x06: R[l][dst] = !R[l][src_a]
        0x07: R[l][dst] = R[l][src_a].rotate_left(R[l][src_b] & 31)
        0x08: R[l][dst] = R[l][src_a].rotate_right(R[l][src_b] & 31)
        0x09: R[l][dst] = (R[l][src_a] as u64 * R[l][src_b] as u64) as u32
        0x0A: R[l][dst] = ((R[l][src_a] as u64 * R[l][src_b] as u64) >> 32) as u32
        0x0B: R[l][dst] = R[l][src_a].wrapping_add(R[l][src_b].wrapping_mul(imm5))
        0x0C: R[l][dst] = R[l][src_a].count_ones()
        0x0D: R[l][dst] = R[l][src_a].leading_zeros()
        0x0E: c = R[l][imm5 & 0x1F]
              R[l][dst] = (R[l][src_a] & c) | (R[l][src_b] & !c)
        0x0F: a_bytes = R[l][src_a].to_le_bytes()
              b_bytes = R[l][src_b].to_le_bytes()
              result[i] = a_bytes[b_bytes[i] & 3] for i in 0..4
              R[l][dst] = u32::from_le_bytes(result)
        0x10: index = (R[l][src_a] + imm5) % 12288
              R[l][dst] = S[index]
        0x11: index = (R[l][src_b] + imm5) % 12288
              S[index] ^= R[l][src_a]
        0x12: R[l][dst] = R[l][src_a].wrapping_add(R[l][src_b]).wrapping_add(imm5)
        0x13: peer = (l + 1 + imm5) % 32
              R[l][dst] = R[peer][src_a]
        0x14: R[l][dst] = R[l][src_a].wrapping_add(imm5)
        0x15: R[l][dst] = R[l][src_a] ^ imm5
        0x16: R[l][dst] = R[l][src_a].rotate_left(imm5 & 31)
        0x17: product = R[l][src_a].wrapping_mul(R[l][src_b])
              R[l][dst] = product.rotate_left(imm5 & 31)
        default: NOP (no state change)
```

### CrossLaneMix(state, cross_lane_map: [u8; 32])

```
// Phase 1: Gather peer values
peer_values = new [[u32; 32]; 32]
for l in 0..32:
    peer = cross_lane_map[l]
    peer_values[l] = R[peer].copy()

// Phase 2: XOR-rotate mix
for l in 0..32:
    for r in 0..32:
        R[l][r] = R[l][r] ^ peer_values[l][r].rotate_left(r & 31)

// Phase 3: Subgroup butterfly
for subgroup_start in {0, 8, 16, 24}:
    stride = 1
    while stride < 8:
        for i in range(subgroup_start, subgroup_start+8, stride*2):
            j = i + stride
            if j < subgroup_start + 8:
                for r in 0..32:
                    a = R[i][r]
                    b = R[j][r]
                    R[i][r] = a.wrapping_add(b).rotate_left(7)
                    R[j][r] = b.wrapping_sub(a).rotate_left(13)
        stride *= 2
```

### DatasetReads(state, pass: u32)

```
for l in 0..32:
    chain = R[l][0].wrapping_add(R[l][4]).wrapping_add(pass.wrapping_mul(0x01000193))

    for r in 0..8:
        index = chain.wrapping_mul(0x01000193).wrapping_add(0x811C9DC5)
        sp_index = index % 12288
        value = S[sp_index]

        dst_reg = (r * 4 + l + pass) % 32
        R[l][dst_reg] = R[l][dst_reg]
            .wrapping_add(value)
            .rotate_left((r + 3) & 31)

        chain = value
            .wrapping_add(R[l][(r + 1) % 32])
            .wrapping_mul(0x01000193)

        S[sp_index] ^= R[l][(r + 2) % 32]
```

### ExecutePass(state, instructions, cross_lane_map, pass)

```
for inst in instructions:
    ExecuteInstruction(state, inst)

CrossLaneMix(state, cross_lane_map)
DatasetReads(state, pass)
```

### ReduceState(state) -> [u8; 32]

```
sp_hash = SHA-256("QelloxHashV1/scratchpad/v1" || S[0..256] as le32 bytes)

hasher = SHA-256("QelloxHashV1/reduce/v1")
for l in 0..32:
    for r in 0..32:
        hasher.update(R[l][r] as le32 bytes)
hasher.update(sp_hash)
return hasher.finalize()
```

### FinalizeHash(work_digest: [u8; 32]) -> [u8; 32]

```
return SHA-256("Qellox/QelloxHashV1" || work_digest)
```

### QelloxHashV1(header: [u8; 80], nonce: u64, epoch: u32) -> [u8; 32]

```
seed = GenerateMiningSeed(header, nonce)
(instructions, cross_lane_map) = GenerateProgram(seed)
state = InitializeState(seed)

for pass in 0..4:
    ExecutePass(state, instructions, cross_lane_map, pass)

work_digest = ReduceState(state)
return FinalizeHash(work_digest)
```

### Target Comparison

```
MeetsTarget(pow_digest: [u8; 32], target: [u8; 32]) -> bool:
    for i in 0..32:
        if pow_digest[i] < target[i]: return true
        if pow_digest[i] > target[i]: return false
    return true  // equal
```

This is equivalent to comparing 256-bit big-endian integers: pow_digest ≤ target.
